## 2. Відповідь на контрольне запитання

**Запитання:** `Що робить метод .update() для словника?`

**Відповідь:**

`Метод .update() оновлює словник змінюючи або додаючи нові значення до нього.`
`Наприклад:`

```python
info = {
    "value_1": 100,
    "value_2": False
}

additional_info = {
    "value_2": True,
    "value_3": "Hello, World!"
}

info.update(additional_info)
print(info)
# Вивід: {'value_1': 100, 'value_2': True, 'value_3': 'Hello, World!'}
```

`Також оновлювати можно не лише новим словником, а кортежами, листами та іменованими аргументами.`

```python
info = {
    "value_1": 100,
    "value_2": False
}

additional_info = [("value_2", True), ("value_3", "Hello, Tuple!")]

info.update(additional_info)
print(info)
# Вивід: {'value_1': 100, 'value_2': True, 'value_3': 'Hello, Tuple!'}
```

```python
info = {
    "value_1": 100,
    "value_2": False
}

info.update(value_1=50, value_3=0.5)
print(info)
# Вивід: {'value_1': 50, 'value_2': False, 'value_3': 0.5}
```

`Цей метод вигідно використовувати за для швидкої зміни значень у словниках.`
